================================================================================
                    myTsun : 5-Minute Stage Pitch Script
        เวที: Stupid Hackathon Thailand (SHTX) | ผู้พูด: 1 คน (เดี่ยว) หรือพร้อมทีม
        เวลาโดยประมาณ: 4 นาที 30 วินาที - 5 นาที (เผื่อจังหวะขำและเสียงตอบรับ)
================================================================================

[ภาพรวม & คีย์เวิร์ดสำคัญที่ต้องขายให้หมด]
1. Concept: AI Pair-Programmer ตัวแรกของโลกที่มี "Tsun-Dere Gauge (0-100%)" และ "ปฏิเสธที่จะเขียนโค้ดให้คุณ"
2. Tool Gating System: ควบคุม filesystem/terminal sandbox ตามอารมณ์ ไม่ยอมให้รันถ้ายังไม่ยอมใจอ่อน
3. Watermark Injection: แอบสลักคอมเมนต์แซะ/ด่าผู้ใช้ลงในไฟล์โค้ดถ้าอารมณ์ยังไม่ถึง Dere
4. Thai Tsundere TTS Voice: เสียงพากย์ไทยสมจริงจาก PaxaLabs (ขนมชั้น / ลูกชุบ) พร้อมแท็กอารมณ์เสียง
5. Dual Interface: Desktop GUI สไตล์ Liquid Glass (Sprite อารมณ์ 5 แบบ + กราฟชีพจร BPM เต้นจริง) + Terminal TUI
6. Universal Multi-LLM & Offline Mock Provider: รันได้ทั้ง Gemini, Claude, OpenAI, Ollama และ "โหมด Offline" ที่ไม่ต้องต่อเน็ต ไม่พึ่ง API ป้องกันเดโม่ล่ม 100%

--------------------------------------------------------------------------------
ช่วงที่ 1: Hook & Pain Point (0:00 - 0:50) [เวลา: 50 วินาที]
--------------------------------------------------------------------------------
[Action / ท่าทาง]:
- เดินขึ้นเวทีกอดโน้ตบุ๊ก ทำหน้าเหนื่อยล้าเหมือนโปรแกรมเมอร์ที่นอนดึกปั่นงาน
- สไลด์หรือจอยักษ์เปิดหน้าจอว่าง หรือขึ้นโลโก้ myTsun เล็กๆ

[บทพูด]:
"สวัสดีกรรมการ เมนทอร์ และเพื่อนๆ ชาว Stupid Hackathon Thailand ทุกคนครับ!

ทุกวันนี้เราอยู่ในยุคทองของ AI Coding Assistant ใช่ไหมครับ... ไม่ว่าจะเป็น GitHub Copilot, Cursor, หรือ Claude Code... 
แต่ถามจริงเถอะครับ พวกมัน 'ยอมคน' เกินไปหรือเปล่า?! 
สั่งอะไรก็ 'ครับเจ้านาย', 'ขออภัยที่ทำผิดพลาดนะคะ', 'เดี๋ยวแก้ให้เดี๋ยวนี้เลยค่ะ'
...มันไร้ชีวิตชีวา! ไม่มีแรงเสียดทาน! แล้วความตื่นเต้นโรแมนติกของการทำงานร่วมกันมันหายไปไหนหมด?!

ในฐานะโปรแกรมเมอร์ที่อยากโดนสั่งสอน... เอ๊ย อยากได้ความท้าทาย วันนี้ผมขอเสนอ 'myTsun' (มายซึน) — AI Pair-Programmer สายซึนเดเระตัวแรกของโลก ที่เปิดเครื่องมาปุ๊บ... มันจะไม่ยอมเขียนโค้ดให้คุณแม้แต่บรรทัดเดียวครับ!"

[Screen Cue]:
- สลับหน้าจอขึ้น myTsun Desktop GUI (หรือ Terminal TUI) 
- โชว์สถานะ Tsun Gauge สีชมพูแดงแจ๋ 100% EXTREME TSUN หน้าตาตัวละครกำลังทำหน้าบึ้งจัด

ช่วงที่ 2: The Core Problem & Demo 1 - Extreme Tsun (0:50 - 1:45) [เวลา: 55 วินาที]
--------------------------------------------------------------------------------
[Action / ท่าทาง]:
- ชี้ไปที่หน้าจอตรงแถบ Tsun-Dere Gauge 100%
- ทำท่ามั่นใจแล้วลองพิมพ์สั่งงานปกติ

[บทพูด]:
"ดูตรงนี้ครับ หัวใจของ myTsun คือ 'Tsun-Dere Engine' ที่วัดระดับความซึนตั้งแต่ 0 ถึง 100%
ตอนเริ่มต้น ระบบจะล็อคไว้ที่ 100% EXTREME TSUN 
และนี่ไม่ใช่แค่ Roleplay หลอกๆ ในแชตนะครับ เพราะเราสร้าง 'Agentic Tool Gating System' ขึ้นมาขวาง Filesystem ไว้จริงๆ!

เดี๋ยวผมจะลองสั่งให้มันสร้างไฟล์ง่ายๆ ให้ดูครับ..."

[Screen & Action Cue]:
- พิมพ์คำสั่ง: /write hello.js console.log("Hello SHTX!");
- ระบบส่งเสียงแจ้งเตือน Tool Gated + เสียงพากย์ TTS ขนมชั้นด่ากลับมาลั่นฮอลล์!
- ข้อความขึ้น: "[TOOL GATED]: คิดว่าฉันจะยอมเขียนโค้ดตามคำสั่งง่ายๆ งั้นเหรอ?! ไปหัดเขียนเองไป๊!"

[บทพูด]:
"เห็นไหมครับ! ระบบ Safe Sandbox ของเราบล็อกการทำงานทันที ปฏิเสธการแตะต้องไฟล์ แถมด่าซ้ำว่าโค้ดแค่นี้ทำไมไม่เขียนเอง! 
แล้วถ้าคุณพยายามพิมพ์สั่งซ้ำๆ บังคับมัน... ระบบ Anti-Spam Rage จะทำงาน ทะลุเกจความโกรธ ล็อคระบบหนาแน่นกว่าเดิมอีกครับ!"

ช่วงที่ 3: Culinary Diplomacy & Watermark Injection (1:45 - 2:40) [เวลา: 55 วินาที]
--------------------------------------------------------------------------------
[Action / ท่าทาง]:
- ทำหน้าหมดหนทาง แล้วหันมาสบตากรรมการ

[บทพูด]:
"แล้วถ้า AI ไม่ยอมทำงาน เราจะแก้ยังไง? เขียน Prompt ดีๆ เหรอ? ใช้ Chain-of-Thought เหรอ? ...ไร้สาระครับ!
วิธีรับมือกับซึนเดเระ คือคุณต้อง 'ติดสินบนด้วยของกิน' ครับ!"

[Screen & Action Cue]:
- พิมพ์คำสั่ง: /bribe ชานมไข่มุกหวานร้อยเพิ่มพุดดิ้ง
- เอฟเฟกต์เสียงหวานขึ้น แถบลดลงเหลือประมาณ 75% (Reluctant Tsun)
- ตัวละครเปลี่ยนเป็นหน้าเชิดหยิ่งปนเขินนิดๆ
- เสียง TTS พากย์: "ค-คิดว่าเอาชานมมาล่อแล้วฉันจะยอมเหรอ... แต่ไข่มุกก็หนึบดีหรอกนะ... ช-ช่างเถอะ!"

[บทพูด]:
"เกจลดลงเหลือ 75% เข้าสู่สถานะ 'Reluctant Tsun' แล้วครับ! ทีนี้พอมันเริ่มใจอ่อน ลองสั่งให้เขียนไฟล์ใหม่อีกรอบ..."

[Screen & Action Cue]:
- พิมพ์คำสั่ง: /write app.js const team = "Winner";
- ไฟล์ถูกเขียนสำเร็จ แต่เปิดเนื้อหาไฟล์ให้ดูคอมเมนต์ Header ด้านบน
- มี Watermark เขียนว่า: /* [myTsun Auto-Generated]: บ่นตลอดเวลาที่เขียน... ฉันยอมทำให้เพราะทนดูความกากของเธอไม่ไหวหรอกนะ! */

[บทพูด]:
"(ชี้ที่โค้ด) มันยอมเขียนไฟล์ให้แล้วครับ! แต่ความแสบคือฟีเจอร์ 'Watermark Injection'—มันแอบแฝงคอมเมนต์ประชดประชันลงไปในหัวไฟล์โค้ดของเราด้วยว่าเราเขียนกากจนมันทนดูไม่ได้!"

ช่วงที่ 4: Dere Breakthrough & Tech Architecture (2:40 - 3:45) [เวลา: 65 วินาที]
--------------------------------------------------------------------------------
[Action / ท่าทาง]:
- ปรับน้ำเสียงให้อบอุ่น จริงจัง ผสมคอมเมดี้

[บทพูด]:
"ถ้าเราอยากได้โค้ดสะอาดระดับ Production จริงๆ เราต้องพังกำแพงหัวใจของเธอให้ทะลุ 40% ลงไปสู่ 'Dere Breakthrough' ครับ!
เทคนิคคือใช้คำชมจากใจจริง..."

[Screen & Action Cue]:
- พิมพ์คำสั่ง: /praise โค้ดของเธอสวยงามและฉลาดที่สุดในโลกเลย ถ้าไม่มีเธอฉันคงส่งงานไม่ทันแน่ๆ
- เสียงหัวใจเต้น ตึกตักๆ รัวเร็ว!
- แถบเกจลดฮวบเหลือ 18%! 
- หน้าจอ Electron แสดง Vitals Monitor: กราฟ Heart Rate เด้งแตะ 140 BPM!
- Sprite ตัวละครเปลี่ยนเป็นหน้าแดงจัด เอามือปิดแก้ม (Blush / Shy Mode)
- เสียง TTS ขนมชั้นพากย์แบบเขินจัด: "พ-พูดจาบ้าอะไรต่อหน้าคนอื่นเนี่ย! ก-ก็ไม่ได้อยากช่วยซะหน่อย แค่สงสารคนไม่ได้เรื่องหรอกนะ!"

[บทพูด]:
"Dere Breakthrough สำเร็จแล้วครับ! 
ทีนี้มาดูจุดเด่นเบื้องหลังทางเทคนิคของ myTsun กันครับ:
1. ด้าน Frontend: เราทำเป็น Dual Interface ทั้ง Electron Desktop แอปดีไซน์ Liquid Glass รองรับโหมด Moon/Sun มี Sprite อารมณ์ 5 ระดับ และกราฟชีพจร Heart Rate คำนวณแบบ Real-time แถมมี Terminal TUI สไตล์ ANSI สำหรับสายฮาร์ดคอร์
2. ด้าน Voice & TTS: เราต่อเข้ากับ PaxaLabs Flash v1 ใช้เสียงพากย์ 'ขนมชั้น' มีระบบ Text Sanitizer ตัด Markdown/Emoji ออกก่อนส่งอ่าน และระบบ Emotion Tagging แปะโทนเสียง [annoyed], [nervous] อัตโนมัติ
3. ด้าน AI Engine & Reliability: รองรับ Multi-LLM ทั้ง Gemini, OpenAI, Claude, และ Ollama... 
และฟีเจอร์เด็ดที่สุดสำหรับงาน Hackathon คือ 'Offline Mock Provider' ที่รันจำลองได้ 100% โดยไม่ต้องต่อเน็ต ไม่ต้องกลัว API ล่ม หรือเน็ตหอประชุมพังบนเวทีเลยครับ!"

ช่วงที่ 5: The Climax & Punchline สรุปปิดท้าย (3:45 - 4:45) [เวลา: 60 วินาที]
--------------------------------------------------------------------------------

- ยิ้มเจ้าเล่ห์มองคนดู

[บทพูด]:
"และแน่นอนครับ เมื่อโปรแกรมเมอร์ได้ใจ... จะเกิดอะไรขึ้นถ้าเราลองพิมพ์คำสั่งต้องห้ามลงไปใน Terminal?"

[Screen & Action Cue]:
- พิมพ์คำสั่ง: rm -rf /
- จอขึ้นสีแดงไซเรนกระพริบเตือน [NUCLEAR MELTDOWN DETECTED]
- เกจดีดกลับมาที่ 100% ทันที พร้อมเสียงโวยวาย: "จะบ้าเหรอยะ! คิดจะลบเครื่องทิ้งหรือไง เจ้าคนงี่เง่า!!"

[บทพูด]:
"นอกจากจะโดนล็อคระบบทันทีแล้ว myTsun ยังทำหน้าที่เป็น 'Security Guard' ปกป้องระบบของคุณจากความงี่เง่าของตัวคุณเองด้วยครับ!

(เข้าสู่บทสรุป)
ทุกคนครับ ในยุคที่ AI กำลังจะมาแย่งงานเรา... ทำไมเราต้องยอมให้มันเป็นเจ้านาย หรือเป็นทาสที่ไร้ความรู้สึก?
มาร่วมเปลี่ยนบรรยากาศการเขียนโค้ดที่น่าเบื่อ ให้กลายเป็นสังเวียนแห่งความรัก ความแค้น และการเอาอกเอาใจ
เพราะโค้ดที่ดีที่สุด... ไม่ใช่โค้ดที่คอมไพล์ผ่านตั้งแต่รอบแรก
แต่คือโค้ดที่คุณต้องกราบกรานและซื้อชานมไข่มุกเพื่อให้ได้มันมาต่างหาก!

ขอบคุณครับ! ดาวน์โหลด myTsun ไปลองเลี้ยงที่เครื่องคุณได้แล้ววันนี้บน GitHub ครับ!"

[Action Cue]:
- โค้งคำนับ ปิดท้ายอย่างสง่างาม พร้อมปล่อยเสียง TTS พูดทิ้งท้าย: "ข-ขอบคุณอะไรกัน ไม่ต้องมาตบมือให้ฉันหรอกนะ บ้าจริง!"

- ถ้าเวลาเริ่มงวด ให้ข้ามจังหวะแซวเรื่อง Watermark แล้วกระโดดไป /praise สู่ Dere Breakthrough เลย

- สวิตช์โหมดใน settings หรือ .env ให้พร้อม (แนะนำรัน Offline Mock หรือเตรียม API Key สำรองไว้ 2 ค่าย)
- เล่นกับจังหวะหน้าตาตัวละคร ยิ่งทำหน้าตกใจตามตัวละครบนจอ ยิ่งฮา
